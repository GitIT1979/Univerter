# Univerter — настольное приложение

Универсальный конвертер документов: DOCX, PDF, Markdown, TXT и изображения (с распознаванием текста).
Это обёртка на Electron вокруг страницы `Univerter.html`: окно, меню, звук и **работа без интернета**
(все библиотеки и языковые данные русского и английского входят в комплект).

## Что внутри

| Файл или папка | Назначение |
|---|---|
| `Univerter.original.html` | исходная страница конвертера (её вы правите) |
| `src/index.html` | та же страница, но с локальными библиотеками; создаётся командой `npm run sync` |
| `src/vendor/` | библиотеки и языковые данные; создаётся командой `npm run vendor` |
| `main.js`, `preload.js` | оболочка Electron (окно, меню, безопасность) |
| `lib/server.js` | локальный сервер на `127.0.0.1`, отдающий страницу (нужен для воркеров и WebAssembly) |
| `scripts/` | подготовка библиотек, проверка, необязательная загрузка модели рукописи |
| `.github/workflows/build.yml` | автоматическая сборка для Windows, macOS и Linux на GitHub |
| `build/icon.png` | значок приложения |

## Быстрый старт (нужен Node.js 20 или новее)

```bash
npm install          # скачает Electron и библиотеки (один раз, нужен интернет)
npm run vendor       # скопирует библиотеки в src/vendor
npm run check        # проверит, что всё на месте
npm start            # запуск приложения
```

## Сборка исполняемого файла

* **Windows:** дважды щёлкните `build-windows.bat` или выполните `npm run dist:win`.
  В папке `dist` появятся установщик `Univerter-1.0.0-win-x64.exe` и портативная версия (запускается без установки).
* **macOS:** `npm run dist:mac` (собирать нужно на Mac).
* **Linux:** `npm run dist:linux` (AppImage и deb).
* **Без установки Node.js у себя:** загрузите папку в репозиторий GitHub и запустите workflow «Сборка приложения»
  (вкладка Actions → Run workflow). Готовые файлы появятся в разделе Artifacts.

## Если вы меняете `Univerter.html`

Замените `Univerter.original.html` новой версией и выполните `npm run sync`, затем снова соберите приложение.

## Рукописный текст без интернета (необязательно)

Модель распознавания рукописи весит около 400 МБ и по умолчанию скачивается при первом использовании.
Чтобы она входила в комплект: `npm run vendor:handwriting`, затем сборка. Сервер сам подключит модель.

## Известные особенности

* Установщики не подписаны: Windows SmartScreen покажет предупреждение («Подробнее → Выполнить в любом случае»),
  на macOS откройте файл через правую кнопку → «Открыть».
* Настройки (галочки, шаблон названия) хранятся между запусками, потому что приложение всегда использует порт 47821.
  Если он занят, берётся случайный, и настройки в этот раз не подхватятся.
* Кнопка «Сохранить все в папку…» зависит от поддержки выбора папки в Chromium; если её нет, используйте «Скачать всё в ZIP».
