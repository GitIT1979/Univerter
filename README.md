# Univerter

Локальный конвертер файлов: TXT, DOCX, PDF, таблицы и изображения.

**Два режима:**
- **Браузерный** — просто откройте `Univerter.html`. Работают текст, таблицы и PDF с текстовым слоем. OCR и точное оформление DOCX ↔ PDF недоступны.
- **С локальным движком** — добавляет распознавание текста на картинках и сканах (Indra) и точную конвертацию DOCX ↔ PDF (LibreOffice + pdf2docx).

Все файлы из папки должны лежать вместе.

---

## Запуск без локального движка

Дважды щёлкните `Univerter.html` — откроется в браузере.

## Локальный движок

### Вариант A — без Docker

#### Что такое PowerShell и как его открыть

**PowerShell** — программа, которая уже есть в Windows. В ней компьютеру дают команды текстом. Это окно с мигающим курсором после строки вроде `PS C:\Users\...>`. Вы вводите только команды из этой инструкции, ничего опасного в этом нет.

**Как открыть в нужной папке:**
1. Откройте папку с файлами в Проводнике.
2. Щёлкните в **адресную строку** сверху (где написан путь к папке).
3. Сотрите путь, введите `powershell` и нажмите **Enter**.

**Как вводить команды:** скопируйте команду из инструкции, в окне PowerShell щёлкните **правой кнопкой мыши** (текст вставится) и нажмите **Enter**.

#### Одноразовая установка

**Шаг 1. Python 3.10 или новее.** В PowerShell введите: `py --version`
- Появилась версия 3.10 или выше (например, `Python 3.12.4`) — переходите к шагу 2. Если версия ниже 3.10, установите новую с https://www.python.org/downloads/.
- «Не распознано» или открылся Microsoft Store — скачайте Python с https://www.python.org/downloads/ и при установке **поставьте галочку «Add python.exe to PATH»**. Затем закройте PowerShell, откройте заново и снова проверьте `py --version`.

**Шаг 2. LibreOffice.** Скачайте с https://www.libreoffice.org и установите как обычную программу (нужен для DOCX → PDF).

**Шаг 3. pdf2docx** (нужен только для PDF → DOCX). В PowerShell введите:

```
py -m pip install pdf2docx
```

**Шаг 4. Indra — распознавание текста на картинках и сканах.** В папке с файлами выполните:

```
py install_indra.py
```

(или дважды щёлкните `install_indra.bat`). Скрипт ставит пакет `indra-ocr` и проверяет, что модель запускается. **При первом запуске Indra скачивает около 76 МБ весов с Hugging Face — интернет нужен один раз**, потом всё работает локально. Если проверка пройдена, вы увидите «✓ Indra работает».

> **Важно про Indra на Windows:** авторы пакета официально тестировали Linux и macOS. На Windows он ставится из тех же зависимостей, но может работать нестабильно. Если проверка не пройдёт — пришлите весь вывод. Альтернатива: запустить движок в Docker.

**Быстрая установка (Windows):** дважды щёлкните `setup.bat`  
Или вручную:
```
py -m pip install -r requirements.txt
py install_indra.py
```

#### Запуск

Откройте PowerShell в папке с файлами и выполните:

```
py univerter_server.py --open
```

Откроется страница Univerter, а в блоке параметров будет зелёная строка «Локальный движок подключён». В окне PowerShell приглашение не вернётся — это нормально, программа работает.

**Режим качества** (для больших файлов): добавьте `?quality=fast` в запрос к `/convert` или используйте параметр в интерфейсе, если он есть. `fast` — меньше размер и быстрее, `high` (по умолчанию) — максимальное качество.

**Если страница не открылась** или написано про порт — порт занят. Нажмите `Ctrl+C` и запустите с другим:

```
py univerter_server.py --port 8766 --open
```

**Важно:**
- Окно PowerShell **не закрывайте**, пока работаете. Закроете — движок остановится.
- Остановить: `Ctrl+C` или закрыть окно.
- Следующий раз установка не нужна — достаточно запустить команду.

### Вариант B — с Docker

**Требования:** Docker Desktop (Windows/macOS) или Docker Engine (Linux).

```bash
docker compose up --build
```

После запуска откройте `http://127.0.0.1:8765/`.

**Примечания:**
- Первый запуск скачает образ (~1–1.5 ГБ из-за LibreOffice) и модель Indra (~76 МБ).
- Файлы не покидают ваш компьютер.
- Остановить: `Ctrl+C` или `docker compose down`.
- Удобнее на Windows, где Indra часто работает нестабильно.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| «pip» или «python» не распознано | Используйте `py`: `py -m pip install pdf2docx`, `py univerter_server.py --open`. Если и `py` не находится — установите Python и перезапустите PowerShell |
| Кнопки не работают, красная плашка | Все `.js`-файлы должны лежать рядом с `Univerter.html` (не открывайте из ZIP) |
| Не найден `univerter_server.py` | PowerShell открыт не в той папке |
| «Страница недоступна» | Запустите с другим портом (`--port 8766`) |
| «Локальный движок не найден» | Проверьте, что окно с программой открыто, и обновите страницу |
| «LibreOffice не найден» | Установите его или укажите путь: `py univerter_server.py --soffice "C:\Program Files\LibreOffice\program\soffice.exe"` |
| «PDF→DOCX ✗» | Выполните `py -m pip install pdf2docx` и перезапустите движок |
| OCR не работает | Выполните `py install_indra.py` и перезапустите, или используйте Docker |
| «⏳ OCR (Indra загружается…)» | Подождите: при первом запуске скачиваются веса (~76 МБ) |
| Indra не заработала | Выполните `py univerter_server.py --check-indra` и пришлите весь вывод |

## Лицензии

Встроенный шрифт DejaVu Sans распространяется по свободной лицензии (Bitstream Vera / DejaVu).

Indra OCR (https://github.com/datalab-to/indra) — отдельный проект со своими условиями: код под Apache-2.0, веса модели — по условиям из раздела License репозитория. Проверьте, что они подходят для вашего случая использования.
